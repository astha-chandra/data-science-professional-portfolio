Featured Projects

Two case studies demonstrating technical data science capability and application within a business context.

Project 01 · Data Science Project

Customer Churn Prediction & Retention Intelligence

✓ Completed

An end-to-end machine-learning project developed using a public banking customer dataset to identify customers at elevated risk of churn and support targeted retention decisions.

Logistic Regression and Random Forest models were compared before threshold optimisation was used to improve identification of genuine churners. Model outputs were then integrated into a three-page Power BI decision-support solution.

Python scikit-learn Random Forest Power BI Machine Learning

Final model: 84.45% Accuracy · 85.03% ROC-AUC · 60.44% Churn Recall · 61.27% F1

Project 02 · Workplace Impact Evaluation

Cloud Cost Forecast Reliability & FinOps Decision Support

✓ Workplace Project

A workplace-based analytical project addressing recurring cloud-cost reporting discrepancies and manual reconciliation within the monthly forecasting process.

Cloudability and FinOps forecast information were reconciled and analysed to identify systematic discrepancy drivers. Predictive analytics and an interactive dashboard were used to support earlier investigation, reporting continuity and more focused governance.

Cloudability FinOps Logistic Regression Power BI Data Quality

Analytical result: ROC-AUC 0.76 · 83% discrepancy recall at a 0.35 decision threshold.
